# Backlog

Deferred work, kept here instead of GitHub issues. This file is the index: each section's items
are in a file of their own in `backlog/`, an item a heading there with its details.

- **Item IDs:** each item has an ID, its section's prefix and a number (`LTR-3`), in its heading.
  Name an item by its ID in changes, commits and other items. IDs are never reused or renumbered:
  a new item takes its section's next ID (the table below) and the table moves on by one.
- **Adding an item:** a heading with its ID and its details in the section's file, and a line
  here.
- **Taking one on:** when work takes an item on, remove it from both.
- **Each item:** a short title, a sentence or two on the problem, then labelled lines (**Fix:**,
  **When:**, **Scope:**) or a short list where it helps. No walls of text.
